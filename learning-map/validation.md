## 行为试用

试用使用独立 Agent、自然语言请求和最小原始材料，产物限制在工作区临时目录；执行者不接收预期答案或拟议修复。所有本地材料均明确标为自拟、虚构的验证材料，不冒充真实课程、教材或项目。需求不足场景由主 Agent 扮演测试用户分轮提供背景，执行者不得自行编造答案。

| 场景与输入 | 实际观察与复核 |
| --- | --- |
| 偏微分方程入门，最初未给目标与基础，只提供一份主题范围短说明 | 执行者提出目标和数学基础两项澄清后停止，没有自行代答或先生成路线。测试者回答仅会单变量微积分，希望两周内认识模型与方法的位置后，生成 6 份 Markdown。主 Agent 阅读了实际页面：地图区分主题与先修，三阶段只到认识与辨认，说明具体模型和求解材料仍缺失；提供两层说明与自测方法，无题目、每日任务、学习记录或 HTML。没有把短说明写成完整课程。 |
| 任务依赖图，基础与目标已齐，提供短讲义、只有目录的书目、只有说明的项目，并明确要求 HTML 总览 | 无重复问卷。生成 11 个文件，包括 9 份 Markdown、1 份 HTML 和 1 份静态检查数据；原材料副本计入文件数。主线讲义与两个候选来源的身份清楚；地图区分包含、先修、成立条件和能力边界；概念以具体任务卡片解释边、环、DAG 和拓扑顺序，并说明局限。两周导览只按周给方向和能力标准，时间估计标出假设。 |
| 在任务依赖图 Wiki 中加入用户备注，再要求将循环依赖例子改得贴近前端构建，其余范围不变 | 执行者只修改概念页与 HTML 对应摘要。主 Agent 对照更新前各文件 SHA-256，确认其余 9 个文件未变，无新增文件，用户备注逐字保留；阅读修改处，确认例子仍表达相互等待及其边界。 |

前两项为独立试用，第三项是在第二项产物与会话上的维护试用，不宣称进行了三次独立验证。主 Agent 检查内容与来源边界，并独立复查两套产物共 175 个链接、85 处锚点引用及四份原材料副本，均通过。执行 Agent 另外检查了 HTML 标签、ID 唯一性与内联 JavaScript 语法；脚本语法检查没有执行页面交互。

## 观察到的问题与修正

首次 HTML 产物的页头含装饰性英文 `LEARNING MAP`，没有完整满足读者可见文字使用中文的要求。主 Agent 阅读产物后，将 Wiki 参考中原来泛指概念标签的中文要求明确到标题、导航与辅助说明。执行者读取修订后局部改为中文，保留必要术语的中英对照。

这项结果属于发现问题后的修正，不将首次产物记为全部通过，也不由单次修正推断以后所有输出都能稳定遵守。没有为此添加独立格式测试或扩展为固定 UI 模板。

## 验证边界

- 行为结论只支持上述短篇离线场景，没有把规格列出的所有场景都记为通过。
- 浏览器工具拒绝本地 `file:` URL，且明确禁止替代路径绕过。因此实际 HTML 渲染、分支点击、链接跳转和窄窗口视觉未验证；本次 HTML 只有内容及静态检查。具体 Markdown 阅读器的显示也未验证。
- 短篇本地材料不能验证真实网络资料的发现、大学课程核查、链接时效、长教材阅读或实际学习效果。
- 未用真实科学英文课程或历史资料验证跨领域选材与语言优先级；相关行为目前有源码规则，不能由中文虚构样例推导为已通过。
- 未进行全局安装、真实宿主自动发现、插件发布或 issue 发布；自动调用配置保持默认，不等于所有宿主已验证可发现。
