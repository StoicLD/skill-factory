# 资料发现与评估

在用户起点和目标足以选材之后，搜集资料前读取本文件。维护已有推荐时，只核查本次涉及的资料和覆盖关系。

## 先看覆盖，再收敛推荐

用主要分支、核心问题和必要先修建立搜集范围。优先找可核查的原始页面与材料，搜索结果用于发现，不代替实际查看。

| 来源 | 主要价值 | 选择与核查重点 |
| --- | --- | --- |
| 世界顶尖大学课程 | 主题结构、先修要求、学习深度、原有练习与实验 | 实际课程大纲、授课版本、可获取课次和作业；学校声誉不能代替内容检查 |
| 经典教科书 | 稳定概念、系统论证与长期学习主线 | 作者、版本、目录及可获取样章；区分仍适用的原理与已变化的实践 |
| 优秀博客与技术文章 | 当前实践、具体取舍、经验与争议 | 作者背景、发布日期、适用条件、引用与实例；经验判断与通用结论分开 |
| 高质量且业界高人气的开源项目 | 工程结构、实际实现、使用示例 | 官方仓库、文档、示例、相关版本与维护情况；热度是发现线索，不能证明适合入门 |
| 其他原始来源 | 填补主题特有的学习需要 | 按领域选论文、标准、官方文档、史料、讲座等，说明各自承担的作用 |

不要求每类来源都出现。例如历史主题可以以史料、研究著作和大学课程为主，理论主题可侧重教材、讲义与论文。优先合适的材料，不凑类别或数量。

科学、技术、计算机科学与数学优先优秀英文原始资料。中国历史等领域按研究对象优先合适的中国资料；其他领域同样按实际来源判断。语言能力影响阅读负担与过渡选择，不自动降低内容质量要求。

将候选资料对应到地图分支。关键分支缺证据时继续定向检索；已足以支持主线与范围说明后收敛，保留有明确用途的拓展入口。没有合适材料的分支标缺口，不用弱相关链接填满。

## 按角色核查

| 角色 | 应实际查看的证据 | 可据此作出的判断 |
| --- | --- | --- |
| 主线材料 | 课程大纲、具体课次与可获取作业；教材目录与可获取样章；项目文档及示例 | 主题覆盖、先修、选读范围与适配程度；具体定位仍以实际看到的内容为限 |
| 拓展材料 | 官方或原作者入口、主题范围、作者与相关版本信息 | 适合补什么、何时进一步看；不把未读正文归纳成已验证结论 |
| 候选材料 | 已取得的检索线索或有限元数据 | 待核查用途与证据缺口；证据不足时不升级为主线推荐 |

“主线已核查”不等于读完全书、学完课程或运行过项目。说明实际看过什么，以及哪些难度、工作量和效果仍属估计。无法取得需要的证据时保留候选身份，选择有证据的替代，或明确交付范围受限。

材料只到目录时，可说明目录中的主题与暂定选读方向；不能据此声称正文讲得清楚或习题难度适中。精确到章节、课次、页码、作业与项目能力的指引都需要相应证据。

在 `lesson / course` 中，写作前还须实际查看支持本讲关键定义、假设和机制的对应正文。课程首页、目录、搜索摘要或其他 Agent 的概括不能单独支持完整机制的已核验声明。只读过其中一节时，讲义依据也限定到这一节及实际补查部分。

解释版本相关接口时，同时核对条目正文与其版本变更说明，再确认当前结论适用的参数、对象类型和配置。仅在来源标题记录版本号，不能证明正文中的行为比较适用于该版本；会改变结论的条件必须进入解释，而非只留在资料表中。

讲义在相关段落附近或末尾列出已核查的节名、锚点或页码，让读者能回到具体材料。区分来源中的事实与例子、Agent 自拟示范和推断；新例子不能继承未经检查的“原作者验证”身份。实际运行代码才记为已运行，并说明环境与版本；无法执行时将输出标为预期。复用图文前核查出处与使用条件，优先独立表述。

## 推荐记录服务于使用决定

主线推荐应让读者辨认以下信息，可以结合正文、表格和链接表达，不强制每份材料复制同一张表：

- 材料名称、作者或机构、来源入口，以及影响理解的版本信息。中文译名不确定时注明为便于识别的自译，不编造官方译名。
- 它解决的学习问题、对应的地图节点和使用阶段。
- 适用基础、应读范围、安排理由，以及为何与该用户目标相适应。
- 实际查看范围、关键判断依据、尚不能确认的部分；版本或时效判断附核查日期。
- 有实际需要时给替代或过渡入口，并说明在内容、练习、理论深度或实践条件上的差异。

候选和拓展条目按其用途简写，仍须让读者辨认证据等级。资料核查说明是来源证据，不是学习者阅读记录。

## 难度与合理性

按实际相关的方面解释难度：数学基础、编程能力、领域经验、语言负担、理论抽象程度与实践工作量。不适用的方面省略，不强制合成总分。

从材料中的要求寻找依据。例如课程明确要求某门先修课，可以解释该先修承担什么作用；未看过作业时，不能声称已经验证作业负担。区分材料自身要求与它相对当前学习者的难点。

判断路线时核对：先修是否得到照顾，材料是否重复或跨越过大，每份主线材料是否有不可替代的用途，所选深度是否支持目标。可用过渡材料或选读范围解决的问题，不必增加一整套重复课程。

时间仅在用户需要时估计，给范围和假设。预设方案改变范围或深度时说明可达成果；不把半年内容简单压进两周，也不安排每日任务。

## 获取条件与费用边界

尽量不用付费在线课程作为推荐；确有其他材料难以替代的价值时，可说明其角色及可获取条件。教材与工具不受这一偏好限制。价格不纳入质量或适配评分，不询问预算，不设计采购方案。

链接能打开不等于正文可获取，官方入口存在不等于已完成内容核查。无法联网时使用真实可访问的本地资料，明确没有开展当前网络搜集；不要编造热门项目、课程近况或可用链接。
