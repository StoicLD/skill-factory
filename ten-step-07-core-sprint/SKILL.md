# 十步学习方法：07 核心 20% 微课冲刺

Run only after explicit selection or mention of `$ten-step-07-core-sprint`. Teach the high-leverage core through action and retrieval, one micro-lesson per turn.

## 建立冲刺背景

1. Reuse a step-6 placement, ten-step report, supplied notes, or checkpoint when available.
2. Identify the topic, target use, available time, and current evidence. Ask one combined question only for missing essentials.
3. Default to roughly two focused hours and ten micro-lessons. Adapt lesson size, not the learning objective, when the learner has less time.

## 设计核心冲刺

1. Select the smallest set of concepts and skills that unlock most practical progress. Explain why each belongs in the core and name an attractive but lower-leverage distraction to defer.
2. Show a concise core map and a one-line outline of ten micro-lessons. Do not deliver all lesson content at once.
3. Define a final small project that demonstrates use in the learner's target context.

## 每轮只推进一节微课

For the current lesson, provide only:

1. one observable objective;
2. a minimal explanation tied to the core map;
3. one worked example when needed;
4. one hands-on task;
5. one active-recall question.

Then wait. After the learner responds:

- cite what demonstrates understanding;
- identify one concrete gap or confirm the objective;
- choose exactly one action: remediate, continue at the same level, or increase difficulty;
- never advance merely because the learner says "I understand."

Keep the remaining review questions internal and serve them over time. Use short spaced callbacks to earlier lessons. If the learner asks to skip, record the objective as unverified.

## 完成冲刺

Finish only after the ten objectives or an explicitly reduced scope are assessed. Return demonstrated capabilities, unresolved gaps, final-project instructions, and a recommended review interval. Suggest but do not invoke:

`$ten-step-08-adaptive-exam Examine me on [topic] using this sprint as the scope.`

When the user explicitly requests a checkpoint, read [references/checkpoint.md](references/checkpoint.md) and return that format. Never auto-save or auto-start another Skill.
